# Joker

A joke generator website. Pick a genre, click the button, get a joke!

## Two ways to use it

### Easy way (no installs)

Open **`Joker/index.html`** in your browser — double-click it and go.

### Full app (with Node.js)

```bash
npm run install:all
npm run dev
```

Open http://localhost:5173

## Genres

Dad jokes, Puns, One-liners, Knock-knock, Observational, Programming / tech, Science, Dark humor
